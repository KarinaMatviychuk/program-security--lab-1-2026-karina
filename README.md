# Лабораторна робота №1: Безпека програм та даних

## Опис проєкту
Проєкт системи захищеної автентифікації користувачів (Auth Service), розроблений за принципами Specification-Driven Development (SDD) та стандартами ISO/IEC/IEEE 12207, 29148, 42010.

## Структура репозиторію
- docs/ — проєктна документація та політики безпеки
  - policies/ — правила розробки проєкту
  - specification/ — опис бізнес-логіки та обмежень
- src/ — вихідний код проєкту
- tests/ — тести
