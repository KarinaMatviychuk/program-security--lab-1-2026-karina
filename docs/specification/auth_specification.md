# Специфікація автентифікації та авторизації "BookTrace"
**Проєкт:** BookTrace (Reading Tracker)  
**Варіант:** 8  
**Автор:** Матвійчук Каріна (група ІПЗ-23-1)  

## 1. Схема Ідентифікації
* **Основний ідентифікатор:** Email-адреса користувача (унікальний рядок).
* **Системний ідентифікатор:** UUIDv4 (`userId`), що генерується модулем `crypto.randomUUID()`.

## 2. Методи Автентифікації (МФА)
* **Перший фактор (Обов'язковий):** Автентифікація за паролем. Пароль зберігається у вигляді засоленого хешу `bcrypt` з 12 раундами обчислень (`cost factor = 12`).
* **Другий фактор (Опційний):** Time-based One-Time Password (TOTP, RFC 6238) через бібліотеку `speakeasy`.

## 3. Модель Керування Доступом (Access Control)
Застосовано комбіновану модель **RBAC + Ownership Check**:
* **Ролі (RBAC):**
  * `READER`: додавання книг, оновлення прогресу читання, створення нотаток.
  * `ADMIN`: перегляд системних даних та списку користувачів.
* **Перевірка власності (Ownership Check):** користувач має право редагувати лише власні книги (`book.userId === session.userId`).

## 4. Політики Безпеки
* **Lockout Policy:** Автоматичне блокування після 5 послідовних помилкових спроб входу.
* **Session Security:** Cookies з атрибутом `HttpOnly` для захисту від XSS-атак.
