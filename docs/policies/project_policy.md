## 1. Стандарти коду та архітектура
* **Технологічний стек:** Node.js, Express, JavaScript (CommonJS), HTML5/CSS3.
* **Структура проєкту:**
  * `src/server.js` — головний файл Express-сервера та API-ендпоінтів.
  * `src/public/` — статичний графічний веб-інтерфейс (HTML/CSS/JS).
  * `src/experiment1.js`, `src/experiment2.js` — експериментальні скрипти хешування.
  * `docs/` — нормативна документація та специфікації.

## 2. Політика версіонування та комітів
Усі коміти у репозиторії Git повинні мати чіткий префікс відповідно до характеру змін:
* `[FEAT]` — додавання нового функціоналу (наприклад, реалізація МФА, додавання книг).
* `[FIX]` — виправлення помилок у коді.
* `[DOCS]` — оновлення документації, політик чи специфікацій.
* `[TEST]` — розробка або запуск тестових і експериментальних скриптів.

## 3. Порядок розробки та злиття (Git Workflow)
1. Для кожної нової лабораторної роботи або великої фічі створюється окрема гілка від `main` (наприклад, `feat/lab3-auth-system`).
2. Код тестується локально в середовищі VS Code на macOS.
3. Після завершення тестування гілка зливається з `main` та відправляється на GitHub (`git push origin main`).
